AR(1) Exact Distribution Explorer

Exact density, distribution function and moments of the least squares estimator \(\hat\phi\) in \(y_t = \alpha + \phi y_{t-1} + \sigma e_t\) (with a trend \(\delta t\) added in cases DT and ST), \(t = 1,\ldots,n\), \(e_t\) i.i.d. \(N(0,1)\), computed by inversion of the characteristic function (Bao and Kan).

Case

Any real \(\phi\) with a fixed start \(y_0\); \(|\phi|<1\) with a stationary start (the slider is restricted accordingly).

\(w_t = \gamma + \gamma_\tau\,(t-\tfrac{n+1}{2}) + \phi w_{t-1} + e_t\), \(w_t = (y_t-y_0)/\sigma\), \(w_0 = 0\); regression of \(y_t\) on \(1\), \(t\) and \(y_{t-1}\).

Normalization \(c_n\) of the plotted variable \(c_n(\hat\phi-\phi)\)

local-to-unity limit when \(|n(\phi-1)|\le 30\); the Cauchy-type limit of the explosive case (DK, DU and DT) beyond that; otherwise the normal approximation. Rescaled to the plotted variable.
